## 这个博客是怎么搭的

- **Hexo**：把 Markdown 变成静态网页
- **Butterfly 主题**：二次元风格，可玩性高
- **GitHub Pages**：免费托管，地址是 `https://acsref.github.io`
- **GitHub Actions**：你只管 `push`，它自动构建并发布

## 为什么用 Actions 而不是本地生成

因为这样换电脑不用装环境：

1. 新电脑上 `git clone` 这个仓库
2. 在 `source/_posts/` 里新建一个 `.md` 文件
3. `git commit` + `git push`
4. 一两分钟后，网站自动更新

甚至可以直接在 GitHub 网页上新建文章——手机也行。
